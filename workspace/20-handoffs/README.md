# 20-handoffs — session summaries

The highest-value habit in this system. At the end of a real work session, you (or your AI) write one file here: what got done, what's still open, what's next.

Name them `YYYY-MM-DD-short-description.md` so they sort chronologically. Next session starts with "read the latest handoff" instead of re-explaining everything.

Use `TEMPLATE-handoff.md` as the starting point.
