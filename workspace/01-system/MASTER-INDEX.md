# Master Index

The one-page map of everything. Keep it current — this is the first place to look (for you and your AI) when you can't remember where something lives.

## Where things live

| Thing | Location |
|-------|----------|
| Active tasks | `10-tasks/TASKS.md` |
| Last session's state | newest file in `20-handoffs/` |
| Brand voice for [Brand] | `50-brands/[brand]/BRAND.md` |
| [Your database] | [where + which doc in 40-tools explains it] |
| [Your hosting] | [where] |
| Credentials | [OUTSIDE this workspace — name the location, not the secrets] |

## Conventions

- Dates: `YYYY-MM-DD` everywhere
- File names: lowercase-with-hyphens
- New stuff: `00-inbox` first, sorted weekly
