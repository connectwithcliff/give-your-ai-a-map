# 50-brands — one folder per brand or project

Each brand gets a folder, and every folder gets a `BRAND.md` — the context file your AI must read before writing anything customer-facing for that brand.

See `example-brand/BRAND.md` for the format. Copy the folder, rename it, fill it in.

The folder name here should match the brand's folder name in your Google Drive, your cloud storage, and your email labels. Same name, every system.
