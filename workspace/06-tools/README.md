# 06-tools — one doc per tool

For every API, service, or tool your AI uses on your behalf, keep one markdown doc here: what it's for, how to call it, the gotchas you've learned.

Example: `supabase.md`, `images.md`, `analytics.md`.

Pattern that works well: when your AI figures out something fiddly about a tool (an auth quirk, a rate limit, a format requirement), have it write the lesson into that tool's doc immediately. Next session it won't rediscover the problem.

Keep the docs here. Keep the KEYS somewhere else — never in this workspace.
